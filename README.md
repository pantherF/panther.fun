# panther.fun

This is my domain name 'panther.fun'. The purpose of this repo is to print this name onto the github contribution graph of 2026. It does so with the `auto-pusher.sh` script, by altering the commit dates for each file that was pushed. If you select 2026 in the graph settings, you will see 'panther.fun' printed by single days, acting as pixels.
The more contirbutions are seen for each day, the higher the probability, that to the file for that day, more random words were added.

## How to make your own text appear on your graph
> :warning: WARNING: This projects script with my date-files will add the panther.fun contribution text to YOUR profile too, so be careful! Don't run the script with my files if you don't want my text on your profile. I have not been able to redo contributions I didn't want for a given day, even after altering the date later!

If you want to add your own text, you need to see the contribution graph for the year of your choice and create a file for each day you want to see colored, it is a bit tedious but it looks cool in the end.

:grey_exclamation: **AGAIN:** Make sure to remove my documents (all of them for each day, except the script) before doing this yourself.
